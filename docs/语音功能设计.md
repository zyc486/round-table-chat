# 语音功能设计文档

## MiMo TTS API 关键信息

### 模型选择

| 模型 | 用途 | 音色来源 |
|------|------|----------|
| mimo-v2.5-tts | 预置音色合成 | 内置精品音色 |
| mimo-v2.5-tts-voicedesign | 文本描述音色 | 自动生成 |
| mimo-v2.5-tts-voiceclone | 音色复刻 | 音频样本 |

### 预置音色列表

| 音色名 | Voice ID | 语言 | 性别 |
|--------|----------|------|------|
| 冰糖 | 冰糖 | 中文 | 女性 |
| 茉莉 | 茉莉 | 中文 | 女性 |
| 苏打 | 苏打 | 中文 | 男性 |
| 白桦 | 白桦 | 中文 | 男性 |
| Mia | Mia | 英文 | 女性 |
| Chloe | Chloe | 英文 | 女性 |
| Milo | Milo | 英文 | 男性 |
| Dean | Dean | 英文 | 男性 |

### 调用格式

```javascript
{
  model: "mimo-v2.5-tts",
  messages: [
    { role: "user", content: "风格指令（可选）" },
    { role: "assistant", content: "要合成的文本" }
  ],
  audio: {
    format: "wav",  // 或 "pcm16" 用于流式
    voice: "冰糖"   // 预置音色 ID
  }
}
```

### 响应格式

```javascript
{
  choices: [{
    message: {
      audio: {
        data: "base64编码的音频数据"
      }
    }
  }]
}
```

### 风格控制方式

**自然语言控制** → 放在 user message 中：
```
用温柔的语调，语速稍慢，带着关心的语气
```

**音频标签控制** → 放在 assistant message 的文本中：
```
(温柔)你今天过得怎么样？
[轻笑]这太有趣了！
```

## 圆桌聊天语音功能设计

### 角色音色配置

每个角色增加字段：
```javascript
{
  id: "char_001",
  name: "鸣人",
  // ... 现有字段
  voice: {
    type: "preset",           // preset | custom
    voiceId: "苏打",          // 预置音色 ID
    style: "活泼热血，语速快", // 风格描述（自然语言）
    description: "少年音，充满活力" // 音色描述（用于 voicedesign）
  }
}
```

### 实现方案

**方案 A：预置音色（最简单）**
- 用户从预置音色列表选择
- 配合风格指令控制语气
- 无需额外 API 调用

**方案 B：音色设计（推荐）**
- 用户描述角色声音特征
- 调用 voicedesign 模型生成
- 更贴合角色人设

**方案 C：音色复刻（高级）**
- 用户上传角色原声样本
- 调用 voiceclone 模型复刻
- 效果最好但需要音频文件

### 建议实现顺序

1. **第一版**：预置音色 + 风格控制
   - 角色设置页选择音色
   - 根据角色性格自动生成风格指令
   - 聊天时点击播放语音

2. **第二版**：音色设计
   - 角色设置页输入音色描述
   - 首次保存时调用 voicedesign 缓存音色
   - 后续复用

3. **第三版**：音色复刻
   - 支持上传音频样本
   - 高级用户使用

## API 调用封装

```javascript
// api/tts.js
export async function synthesizeSpeech(text, voiceConfig, style = '') {
  const messages = []

  // 风格指令（可选）
  if (style) {
    messages.push({ role: 'user', content: style })
  }

  // 合成文本（必须在 assistant 消息中）
  messages.push({ role: 'assistant', content: text })

  const response = await fetch('/api/chat/completions', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'api-key': API_KEY
    },
    body: JSON.stringify({
      model: 'mimo-v2.5-tts',
      messages,
      audio: {
        format: 'wav',
        voice: voiceConfig.voiceId || '冰糖'
      }
    })
  })

  const data = await response.json()
  const audioBase64 = data.choices[0].message.audio.data

  // 播放音频
  return playAudioFromBase64(audioBase64)
}

function playAudioFromBase64(base64) {
  const audio = new Audio(`data:audio/wav;base64,${base64}`)
  return audio.play()
}
```

---

## 注意事项

1. **文本位置**：合成文本必须在 assistant 消息，不能在 user 消息
2. **音频格式**：非流式用 wav，流式用 pcm16
3. **音色选择**：中文角色建议用冰糖/茉莉/苏打/白桦
4. **风格控制**：自然语言描述放在 user message，标签控制放在文本中
5. **延迟**：当前流式输出暂未上线，需等待更新
