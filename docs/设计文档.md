# 圆桌聊天 - 设计文档

## 1. 项目概述

### 1.1 项目简介
圆桌聊天是一个基于 Web 的 AI 角色对话应用。用户和多个 AI 角色（如动漫人物）围坐在一张圆桌旁进行对话，具有生动的动画效果和沉浸式的聊天体验。

### 1.2 核心特色
- **圆桌场景**：2D 卡通风圆桌，角色围坐，直观展示对话关系
- **AI 扮演**：每个角色有独立性格，由 LLM 扮演回复
- **多种交互模式**：全员轮流、@指定、自由触发
- **动画效果**：聊天气泡、角色表情、发言动画

### 1.3 目标用户
- 想同时与多个 AI 角色对话的用户
- 喜欢动漫/游戏角色的粉丝
- 想体验多角色聊天场景的用户

## 5. LLM 接口设计

### 5.1 Prompt 结构

```
系统消息:
你正在参加一个圆桌聊天。你的角色是 {name}。
角色设定: {description}
性格: {personality}
说话风格: {speakingStyle}

请严格按照角色设定回复，保持角色的一致性。
回复要简洁自然，像真实聊天一样，不要超过 100 字。

当前聊天室中有以下成员:
- 用户 (我)
- {其他角色名字和简介}

---
历史消息:
{最近 20 条消息}

---
用户消息: {当前消息}
```

### 5.2 模式处理

**全员轮流模式 (round_robin)**
- 用户发消息后，依次调用每个角色的 LLM
- 每个角色能看到前面角色的回复
- 间隔 500ms 依次展示

**@指定模式 (mention)**
- 用户 @ 某角色后，只调用该角色的 LLM
- 其他角色不回复

**自由触发模式 (free)**
- 用户发消息后，由一个"主持人" LLM 判断哪些角色应该回复
- Prompt: "根据以下对话内容，判断哪些角色会想回复，返回角色 ID 数组"

### 5.3 API 调用封装

```javascript
// api/llm.js
export async function chatWithCharacter(character, messages, userMessage) {
  const systemPrompt = buildPrompt(character)
  const response = await callLLM({
    system: systemPrompt,
    messages: [...messages, { role: 'user', content: userMessage }]
  })
  return response
}
```
