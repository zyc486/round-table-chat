# 🎭 圆桌聊天

一个基于 Web 的 AI 角色对话应用。用户和多个 AI 角色围坐在圆桌旁进行对话。

## ✨ 功能特色

- **圆桌场景**：2D 卡通风圆桌，角色围坐，直观展示对话关系
- **AI 扮演**：每个角色有独立性格，由 LLM 扮演回复
- **多种交互模式**：
  - 全员轮流：所有角色依次回复
  - @指定：指定某个角色回复
  - 自由触发：AI 判断谁会回复
- **动画效果**：发言动画、思考中动画、气泡动画
- **表情系统**：根据消息内容显示角色表情
- **主题切换**：6 种精美主题可选
- **预设角色**：内置 6 个经典动漫角色

## 🚀 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

访问 http://localhost:3000

## 📖 使用指南

### 1. 添加角色

- 点击「管理角色」进入角色管理页
- 可以「新建角色」自定义，或点击「预设角色」快速添加
- 角色需要设置：名字、描述、性格、说话风格

### 2. 开始聊天

- 在底部输入框输入消息
- 选择聊天模式：
  - **全员轮流**：你说一句，所有角色依次回复
  - **@指定**：用 `@名字` 指定某个角色回复
  - **自由触发**：AI 判断哪些角色会想回复

### 3. 个性化设置

- **主题切换**：设置 → 主题设置，选择喜欢的主题
- **API 配置**：设置 → API 设置，配置你的 API 密钥

## 🛠️ 技术栈

- Pinia

```
│   └── character/# 角色相关

```
